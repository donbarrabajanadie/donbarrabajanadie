### 🐚 MiniShell en C
Implementación y depuración de una shell sencilla en un entorno Linux de prácticas.

- Desarrollo de comandos internos, como `pwd` y `cd`.
- Trabajo con procesos y ejecución de órdenes.
- Compilación y pruebas dentro de un sistema de archivos de Linux preparado para la práctica.

**Tecnologías:** C · Linux · Git · Make

### 🎾 Aplicación de gestión de torneos deportivos
Proyecto académico en Java para gestionar información de torneos y resultados deportivos.

- Programación orientada a objetos.
- Persistencia de datos y conexión con una base de datos.
- Trabajo con interfaz gráfica y herramientas de construcción del proyecto.

**Tecnologías:** Java · JavaFX · Hibernate · MySQL · Maven

- Implementación de versiones paralelas de **Bucket Sort** y **QuickSort**.
- Uso de `ExecutorService` para gestionar tareas concurrentes.
- Comparación y análisis del funcionamiento de las implementaciones.

**Tecnologías:** Java · Concurrencia · ExecutorService

### 🔄 Automatización de procesos con n8n
Diseño de workflows para automatizar pasos de un proceso y tratar los datos que circulan entre nodos.

- Configuración de nodos y campos.
- Uso de valores booleanos y lógica de flujo.
- Validación y transformación de datos dentro del workflow.

**Tecnologías:** n8n · Automatización · Tratamiento de datos
